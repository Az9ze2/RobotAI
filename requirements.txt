# ============================================================================
# NOTES ON CONFLICT FIXES
# ============================================================================

# 1. torch==2.9.1 → 2.9.0
#    2.9.1 does not exist; 2.9.0 is the correct latest stable version.

# 2. transformers==4.35.0 → 4.51.3
#    nemo-toolkit[asr]==2.4.0 requires transformers>=4.51.0,<=4.52.0.
#    The old 4.35.0 pin caused a hard ResolutionImpossible error.

# 3. sentence-transformers==2.2.2 → >=3.0.0
#    sentence-transformers 3.x is required to support transformers>=4.51.

# 4. pymilvus==2.3.3 → 2.4.9
#    2.3.3 pins grpcio<=1.58.0 which has no Python 3.12 pre-built wheel.
#    Building from source fails with ModuleNotFoundError: No module named
#    'pkg_resources' even with setuptools installed. 2.4.9 resolves this.

# 5. grpcio-tools is NOT pinned here intentionally.
#    grpcio-tools 1.59.3 requires protobuf<5.0, but nemo installs protobuf 5.x.
#    grpcio-tools is a dev/compile tool for .proto files, not a runtime dep.
#    It is not needed by any package in this stack at runtime.
#    If you explicitly need it: pip install grpcio-tools>=1.67.1 (supports protobuf 5.x)
